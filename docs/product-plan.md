# 动态研究系统一阶段

## 目标

把静态观察榜升级为数据驱动研究系统原型：

- 产业链节点来自 `data/sectors.json`。
- 公司池来自 `data/companies.json`。
- 证据流来自 `data/evidence.json`。
- 观察榜按 `data/scoring.json` 动态计算。

## 已覆盖能力

- 产业链节点切换。
- 每个节点展示瓶颈、反证问题、关联公司。
- 公司卡片展示动态总分、评分分解和最新证据。
- 隐形赢家观察榜由评分规则自动排序。
- 证据流按日期排序展示，并标记情绪和置信度。

## 下一阶段

建议二阶段接入轻量后端：

- FastAPI + SQLite。
- 维护公司、节点、证据和评分规则。
- 支持手动新增证据、编辑公司卡位、调整评分因子。
- 保留 JSON 导入导出能力，方便静态部署和数据备份。
